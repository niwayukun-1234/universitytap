# UniversityTap

①同志社生に向けて、今大学キャンパスで学生証にICチップを埋め込み、それをスマートフォンと連携させて、 誰がどこにいるのかという位置情報を各教室に学生証タッチする場所をつくり、そのタッチ情報で友達同士で誰がどこの教室にいるか共有できるようなアプリを作ろうと思ったので、簡易的なウェブアプリを作って欲しいです。 フレンドとのチャット機能をつくり、そこで写真も送れるようにして。また、いる教室をタッチする際にメモとして追記の情報も書けるようにして。またログイン後に友達がどこの教室にいるかわかるような画面にうごくようにして。 学籍番号に123456789,名前に丹羽長秀を入力して、はじめるボタンを押したら、位置情報項目、フレンド項目、時間割項目の３つのボタンを下に作り、最初の画面はどこの教室にいるかがわかる画面にして。 今出川にある館の教室情報をすべてタッチできる場所の候補として追加してください。 またフレンドを一人西嶋隆矢という人物を追加して、フレンド名をタップしたらフレンドの位置情報・時間割を見れるようにして。また自分やフレンドの時間割の見方を月～日まで表形式で視覚的に見やすいようにして。 また、フレンドごとではなく、下の項目に場所という項目を新たにつくり、どの教室に誰がいるかということも確認できるようにして。 また左上の名前が書かれたところを押せば、自分のプロフィールを編集できるようにして、項目を学部・学科・サークル・アイコンの変更・ゼミなどにして。 ②・フレンド追加機能 ・教室数が不足 ・最初の画面で新規会員登録をできるように ・プロフィールアイコンをユーザーが変更できるように ・チャット機能でファイルの送信機能を追加 ・学籍番号は非表示 ・管理画面で登録者が一覧できるように ・時間割を七限まで ・時間割を土曜日まで 以上の要素を追加して ③・リロードするとログイン情報消えるので改善して ・﻿居る場所をタッチする際、学生証タッチではなくただのタッチ、タッチしてチェックインではなく入室という表記にする ・﻿フレンドどうしでチャットができるグループを作れる機能をつける ・名前をユニバーシティタップとして、登録する際に大学を選ばせ、それに合わせてサービスを変えれるようにする。 ・その大学の候補は京大・同志社大を今の所選択肢として入れ、今の既存のサービスは全て同志社側のものとする ・時間割を入れる欄に授業以外もサークル・バイト・部活・その他も入れれるようにし、予定ごとに好きなように自分で色を変えれるようにする利用規約を作る ・どの大学が何人使ってるか把握できるようにする ・予定に入れた内容をGoogleカレンダーにそのまま入れ込むことができるような機能性にする ④・新規会員登録画面の丹羽長秀を氏名に変更 ・デフォルトではフレンドは誰も登録しないで（西嶋隆也が初期からフレンドに追加されているので修正して） ・新規会員登録時に大学を選択できるように（同志社大学、京都大学） ・まずは、同志社大学を選択した場合のみサービスを利用できるように ・メールアドレスの登録 ・学籍番号の入力・保存機能は削除 ・１つのメールアドレスにつき１つのパスワードのみ対応 ・デフォルトで経済学部、経済学科を任意に変更 ・ログイン時に入力する内容をメールアドレスとパスワードにする ・ユーザーが閲覧できるのはどの大学に何人いるかの情報のみで、フレンド以外で登録している人の情報は非表示で
